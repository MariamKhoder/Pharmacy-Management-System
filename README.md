# Pharmacy Management System (JavaFX)

##  Project Overview
A Desktop Application developed using **JavaFX** to manage pharmacy operations efficiently. This project was created as an academic assignment to apply **Object-Oriented Programming (OOP)** and **GUI development** concepts.

##  Key Features
- **Inventory Management:** Add, update, and delete medicine records.
- **Sales System:** Process transactions and calculate totals.
- **User Authentication:** Secure login for pharmacists and administrators.
- **Database Integration:** (Mention if you used MySQL, SQL Server, or File Storage).

##  Technical Implementation
- **JavaFX:** For building a modern and responsive user interface.
- **CSS:** To style the application components.
- **MVC Pattern:** Separation of logic, view, and data for better code maintainability.
